# 💳 UPI Transaction Dashboard | Power BI

## 📌 Project Overview

This project showcases an interactive **UPI Transaction Dashboard** built using Power BI to analyze digital payment performance across transaction volume, value, success rate, and failure rate.
The dashboard transforms raw transaction data into meaningful insights to track growth, identify issues, and compare app-wise performance.

---

## 🎯 Business Objective

The objective of this project is to analyze UPI transaction data and uncover patterns that impact transaction success and digital payment growth.

Key goals:

* Track transaction volume and value trends
* Monitor success and failure rates
* Compare performance across UPI apps
* Generate insights for improving transaction reliability

---

## 📊 Dataset Description

The dataset contains transaction-level UPI data with the following fields:

* Date
* Payment App
* Transaction Volume
* Transaction Value
* Success Rate
* Failure Rate
* Month
* User Count (if available)

The dataset was cleaned and structured using Power Query before visualization.
